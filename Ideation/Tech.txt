# Technical Stack and Architecture (Strict IDE Guidelines)

## 1. System Requirements & Environment
To ensure compatibility with the latest reinforcement learning libraries and prevent dependency conflicts, the virtual environment must be configured with the following specific versions:

*   **Language:** Python 3.10, 3.11, 3.12, or 3.13. (Do not use Python 3.9 as support has been dropped). 
*   **Deep Learning Backend:** PyTorch (torch >= 2.8). This is required for the latest security mitigations and performance stability.
*   **RL Framework:** `stable-baselines3[extra]` (version >= 2.9.0). The `[extra]` flag is necessary as `pandas` and `matplotlib` are no longer core dependencies but are required for our data generation and plotting.
*   **Environment API:** `gymnasium` (version >= 0.29.1, < 2.0). *Crucial Instruction for AI IDE:* Do not use the deprecated `gym` library; strictly use `gymnasium`.
*   **Data Handling & Math:** `numpy` (for matrix operations) and `pandas` (for time-series manipulation).

## 2. Directory Architecture
The project must be modularized exactly as follows to ensure the training loop can easily import the custom environment without circular dependencies.

4. Training Constraints (Stable Baselines3 Integration)
When writing scripts/train_agent.py, the AI must instantiate the PPO algorithm using a custom multi-input policy, as our state is a dictionary.

Policy Network: Must use "MultiInputPolicy" (not "MlpPolicy").

Normalization: Use VecNormalize to stabilize the continuous components of the state vector (like elapsed time and battery percentage) before they are fed into the neural network.

Callbacks: Implement a checkpoint callback to save the model every 10,000 timesteps to prevent loss of progress during local training.
